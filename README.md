# Chat Export Cleaner

Drop your ChatGPT `conversations.json` (or the whole export .zip) — get clean, readable Markdown. Per-conversation `.md` files, zip download, search, and a readable viewer.

**100% client-side.** Your file never leaves your browser. Works offline after load.

## Use it

Get your export: ChatGPT → Settings → Data controls → Export data → unzip → drop `conversations.json` here.

## Files

- `index.html` — the entire app (one file, no build, no backend)
- `sample-conversations.json` — tiny demo export to try it safely
